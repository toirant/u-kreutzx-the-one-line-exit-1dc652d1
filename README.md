Entry for the make.fun bounty [The One-Line Exit](https://make.fun/bounty/u-kreutzx-the-one-line-exit-1dc652d1) — one resignation letter, exactly one line long, whose only job is to be funny.

## The entry

> I quit — not because the job was hard, but because the office goldfish got promoted over me and honestly, it earned it.

119 characters, one line.

## Run

```sh
node main.ts
```

`main.ts` validates the line against the bounty gate (UTF-8 text, 1–140 characters, exactly one line, not only whitespace) and writes it to `/output/entry.txt` (falling back to `./output/entry.txt` if `/output` is not writable).
